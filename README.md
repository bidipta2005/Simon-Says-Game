# Simon Says Game 

A fun and interactive memory game inspired by the classic **Simon Says**. Test how far your brain can go as you repeat the color patterns correctly!

## Features

- Classic **Simon Says** gameplay
- Pattern generation and memory challenge
- Increasing difficulty with each round
- Visual and audio feedback
- Responsive and simple UI
